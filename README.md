Am creat această aplicație cu scopul de a învăța, de a structura mai eficient datele din proiectele mele anterioare și de a-mi consolida cunoștințele în framework-ul Qt (C++). Pe lângă sistemul de autentificare și creare cont, aplicația oferă 5 module principale:

Tracker Antrenamente: Afișează dinamic exerciții specifice și ilustrații în funcție de split-ul selectat de utilizator (ex: Push-Pull-Legs, Bro-Split).

Jurnal Alimentar (Calorii): Permite înregistrarea meselor zilnice și calculează automat totalul caloric pentru gestionarea deficitului.

Monitorizare Hidratare: Un modul dedicat pentru contorizarea rapidă a consumului zilnic de apă.

Cronometru Antrenament: Un timer interactiv folosit pentru a măsura cu precizie execuția exercițiilor sau timpul de pauză.

Gestionare Profil: O secțiune securizată unde utilizatorul își poate actualiza datele personale pe baza parolei.
Pentru a asimila cât mai multe cunoștințe, am explorat în profunzime arhitectura framework-ului Qt, integrând o gamă variată de clase și widget-uri (precum QVBoxLayout, QHBoxLayout, QLineEdit, QTimer sau structuri de date ca QMap). De asemenea, am pus un accent puternic pe securizarea aplicației prin validarea datelor și gestionarea erorilor. Am implementat mecanisme de prevenire a acțiunilor nedorite, afișând avertizări clare pentru utilizator în cazul input-urilor invalide (de exemplu: câmpuri lăsate goale la logare sau parole incorecte la actualizarea profilului).

And for the english viewers there is an adapted version :

I created this application to expand my programming skills, efficiently process data from previous projects, and deepen my understanding of the C++ Qt Framework. Alongside a fully functional Log-In/Sign-Up system, the application features 5 core modules:

Workout Tracker: Dynamically displays specific exercises and visual guides based on the user's selected workout split.

Calorie Tracker: Allows users to log meals and automatically calculates daily caloric intake to help manage a caloric deficit.

Hydration Monitor: A quick-access tool to track and visualize daily water consumption.

Workout Timer: An integrated stopwatch for timing exercise execution or rest periods.
Profile Management: A secure section allowing users to update their personal information requiring password confirmation.
To maximize my learning, I extensively explored the Qt framework's architecture by implementing a wide variety of classes and widgets (such as QVBoxLayout, QHBoxLayout, QLineEdit, QTimer, and data structures like QMap). Furthermore, I focused heavily on application security through data validation and error handling. I implemented fail-safes and clear user alerts for invalid inputs (e.g., preventing submissions with empty fields or incorrect passwords in the profile module)
